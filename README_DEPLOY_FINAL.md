## 🚀 DEPLOY EN 3 PASOS

### 1. Subir a GitHub

```bash
unzip mixingai-v30-complete.zip
cd mixingai-v30-complete

git init
git add .
git commit -m "MixingMusic.AI V30 - #1 Music AI Award 2026"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/TU_REPO.git
git push -u origin main
```

### 2. Conectar en Render

1. Dashboard Render → "New" → "Web Service"
2. Conecta tu repo GitHub
3. Render detecta `render.yaml`
4. Click "Apply"

### 3. Variables de Entorno

```
VITE_SUPABASE_URL=tu_supabase_url
VITE_SUPABASE_ANON_KEY=tu_supabase_anon_key
VITE_MP_ACCESS_TOKEN=tu_mercadopago_token
```
