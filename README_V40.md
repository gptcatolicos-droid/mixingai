## 🎨 NUEVO DISEÑO VISUAL

### Colores (Design Tokens):
```css
--bg-0: #0B0D12          /* Background principal */
--bg-1: #11131A          /* Background secundario */
--panel-1: #181C26       /* Paneles */
--accent: #8B5CF6        /* Púrpura acento */
--text-primary: #F5F7FA  /* Texto principal */
```

### Componentes Rediseñados:

#### TopBar:
- Logo con marca "M"
- Navegación con iconos
- Badges de plan y créditos
- Usuario circular

#### Transport:
- Controles play/pause/record
- Display de tiempo digital
- BPM editable
- Botones de zoom

#### Track Cards:
- Color bar lateral (por stem)
- Waveform visual
- Metadata (nombre, tipo)
- Controles Vol/Pan inline
- Botones EQ y Plugins

#### Preset Selector:
- Cards por género (Pop, Rock, Hip Hop, etc.)
- Visualización de frecuencias
- Aplicación con 1 clic

#### Mix Bus:
- EQ de 3 bandas (Bass, Mid, High)
- Sliders verticales
- Indicadores de ganancia
- Efectos (Reverb, Delay, Widener)

#### LUFS Meter:
- Display grande
- Targets Spotify/YouTube
- Safe/warning zones
- FFT analyzer integrado
